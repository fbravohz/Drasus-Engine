> 🔶 **Generalizado por ADR-0154** — Bulk + Delta deja de ser *la* arquitectura de ingesta y pasa a ser el mecanismo de **una** de las tres vías canónicas (interfaz de programación autenticada / credenciales de bróker / exportación manual desde el terminal). Dos consecuencias sobre lo que sigue: (1) **los proveedores nombrados aquí pierden todo carácter normativo** — Drasus no provee datos de mercado, ningún proveedor ni URL es invariante de arquitectura, y toda fuente es dato de configuración elegido por el usuario; (2) el mecanismo declarado abajo describe el canal HTTP anónimo de archivos comprimidos, que **no es universal** — hay fuentes por canal autenticado, por formato binario propietario y por archivo local sin red. El puerto de descarga admite esas variantes; el orquestador no cambia.

### **ADR-0034: Ingesta Híbrida Soberana (Bulk S3 + API Delta)**

*   **Decisión:** Implementar un pipeline de ingesta dual que prioriza la descarga masiva de archivos comprimidos desde buckets públicos (AWS S3, Binance Vision) para históricos y utiliza APIs REST exclusivamente para sincronizar el "Delta" (el hueco desde el último volcado hasta el minuto actual).
*   **Objetivo:** Saturar el ancho de banda del usuario y reducir el tiempo de carga inicial en un factor de 100x respecto a consultas API secuenciales.

*   **Mecanismo:**
    *   **Bulk Ingest:** Descarga concurrente con cliente HTTP nativo Rust (`reqwest`/`hyper`) de archivos `.zip` o `.csv.gz`.
    *   **API Delta:** Sincronización final vía adaptadores directos de NautilusTrader (Binance, IBKR, Oanda v20).
*   **Ventaja:** Evita bloqueos por *Rate Limits* y garantiza la disponibilidad instantánea de años de histórico.
*   **Costo:** Lógica de deduplicación y resolución de continuidad en la frontera de unión Bulk/Delta.
*   **Trazabilidad:** [sovereign-data-fetcher.md](../features/sovereign-data-fetcher.md).

* **Ver también:** ADR-0107 — Los adaptadores de ingesta API Delta se rigen por las reglas de gobernanza de NautilusTrader (crates v2, brechas de adaptadores). ADR-0154 — Doctrina de procedencia del dato (Drasus provee conectores, no datos), tres vías de ingesta, tabla de capacidades por bróker y frontera de responsabilidad sobre la calidad del dato.
